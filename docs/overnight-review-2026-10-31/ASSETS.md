# Optional private asset preparation

Use only an existing authorized CoD4 installation. No fonts, IWI files, PCM, IWD archives, fastfiles or exported menu/material inventories are included in this delivery. The screenshot is a rendered result, not an asset bundle.

## Offline export supported at the documented checkpoint

This combined review branch already includes both series and the repaired database work-publication path; do not apply the cumulative patches again. After the build helper has created the local dependency toolchain:

```sh
cd "$REPO"
EXPORT_BUILD="$BUILD_ROOT/export"
GAME_DIR=/absolute/path/to/authorized/CoD4
PRIVATE_EXPORT=/absolute/path/to/new/private-export
EXPORT_HOME=/absolute/path/to/new/isolated-export-home
cmake -S . -B "$EXPORT_BUILD" -G Ninja -DKISAK_PLATFORM=linux \
  -DKISAK_BUILD_UI_ASSET_EXPORT=ON -DCMAKE_BUILD_TYPE=Debug \
  -DCMAKE_C_COMPILER="$CC" -DCMAKE_CXX_COMPILER="$CXX" \
  -DCMAKE_C_FLAGS=-m32 -DCMAKE_CXX_FLAGS=-m32 \
  -DCMAKE_TOOLCHAIN_FILE="$BUILD_ROOT/local-dependencies.cmake" \
  -DCMAKE_RUNTIME_OUTPUT_DIRECTORY="$EXPORT_BUILD/bin"
cmake --build "$EXPORT_BUILD" --target KisakCOD-ui-asset-export -j "$JOBS"
KISAK_UI_ASSET_EXPORT_DIR="$PRIVATE_EXPORT" KISAK_UI_ASSET_EXPORT_MENUS=1 \
  "$EXPORT_BUILD/bin/KisakCOD-ui-asset-export" \
  +set fs_basepath "$GAME_DIR" +set fs_homepath "$EXPORT_HOME" \
  +set dedicated 2 +set useFastFile 1
```

The output path must be absolute and empty; new directories are created mode 0700 and existing ones must have that mode. Require exit 0 and `asset_export=complete`. A failure may leave partial outputs: preserve them for diagnosis and use a new empty directory for a later run. This one-shot tool uses actual database loading and exits before networking initialization. It does not establish normal game shutdown. QEMU invocation can wrap this executable explicitly as described in BUILD.md.

Resolve required image names from the exported material descriptions; extract only those `images/<name>.iwi` entries from the authorized installation's IWD ZIP archives into a private image directory. Preserve genuine font/material associations and mip chains. The admitted tested assets use gamefonts_pc, devfonts, qerfont, 3_cursor3 and button_highlight_end; actual exports are authoritative. The genuine `$white` is generated by the engine's 1x1 RGBA255 definition and has no IWD entry.
